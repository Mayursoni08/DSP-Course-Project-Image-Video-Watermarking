# Changelog

All notable changes to this project are documented here.

## 1.0.0 — 2026-09-04

- Added blind keyed level-3 DWT + block-DCT + STDM image watermarking.
- Added alternative DWT-DCT-SVD parity-QIM backend.
- Added CRC/HMAC payload framing, keyed whitening, convolutional coding, and soft Viterbi decoding.
- Added semi-blind ORB/RANSAC, homography, and ECC geometric registration.
- Added separable temporal-Haar video embedding, keyframe-aligned output, phase search, and multi-frame voting.
- Added JPEG, H.264/H.265, spatial, frame-drop, and frame-rate attack suites.
- Added reproducible figures, JSON/CSV/Markdown reports, CLI manifests, tests, packaging, and CI.
